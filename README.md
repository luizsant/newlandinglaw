# newlandinglaw

Landing page estática — **Luiz Santiago Advocacia e Consultoria** (defesa do executado empresário).

## Conteúdo

- `index.html` — página principal
- `assets/` — imagens (marca, hero, rodapé, certificados, documentos)
- `vercel.json` / `_redirects` — redirecionamentos (ex.: URL antiga)

## Deploy

Compatível com [Vercel](https://vercel.com), Netlify ou qualquer hospedagem de ficheiros estáticos. Raiz do projeto = pasta publicada.

## Desenvolvimento local

Abrir `index.html` no browser ou servir a pasta com um servidor estático (ex.: `npx serve .`).
